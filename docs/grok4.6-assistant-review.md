## ภาพรวม

ระบบตอนนี้มี **13 สายงาน · 72 เครื่องมือเดี่ยว · 13 หน้า “คิดทั้งงาน”** โครงหลักดีมาก — ค่าคงที่รวมใน `constants.ts`, กางสูตรได้, จัดชั้นความเสี่ยง A/B/C, กราฟประกอบผล, มือถือคิดมาแล้ว

จุดที่ยังต้องแก้ก่อนวางใจใช้หน้างานจริงมี 3 กลุ่ม:

1. **สูตรที่ตัวเลขผิดจริง** — ตาราง P–T น้ำยาแอร์คลาด ~20 °C, ท่อ PVC เทียบ ID กับขนาดเรียก, เหล็กทับหลังคูณเกิน ~3 เท่า
2. **ผลลัพธ์ที่ตอบเหมือนสำเร็จทั้งที่เกินช่วง / นับซ้ำ / ชนิดแนวไม่ต่างกัน**
3. **หน้า “คิดทั้งงาน” ไม่กางสูตร และฟอร์มยังพึ่ง `min/max` ของเบราว์เซอร์**

ด้านล่างเรียงตามความสำคัญ ให้ทีมหยิบไปแก้ทีละข้อได้เลย

- **หม้อแปลง LED** (`calcLed`): เกินตาราง 300 W แล้วปัดเป็นขั้น 50 W แบบเงียบ — ควรบอกว่าเกินไซซ์ที่ร้านทั่วไปมี
- **แปลงหน่วยไฟฟ้า** (`calcElecUnit`): 1 HP = 746 (mechanical) — มอเตอร์ไทยมักใช้ metric 735.5 W; ใส่ตัวเลือก
- **น้ำหนักเหล็ก H/W/C**: ตารางกิโลกรัม/เมตรฝังในไฟล์ ไม่ระบุเกรดเบา/เต็ม และไม่ได้อยู่ใน `constants.ts`
- **ตัดอลูมิเนียม** (`calcAluCut`): หักหน้าตัดเฟรมเฉพาะด้านกว้าง ด้านสูงไม่หัก — มุม 45° ต้องสมมาตรทั้งสองด้าน
- **ยาแนว** ข้อความแทนค่าเขียนหน่วยผิดเป็น “ม./ตร.มม.” (สูตรตัวเลขถูกแล้ว ตาม ISO 13007)
- **ปริมาณสี** `pack()`: กรณีลงตัวถังใหญ่จะขึ้น “1 ถังใหญ่ + 0 แกลลอน”
- **กระเบื้องบิ้วอิน** (`calcHandymanTile`) ซ้ำกับหมวดกระเบื้องแต่ยาแนวคิดหยาบ `พื้นที่ × 0.4` (สูงกว่าสูตร ISO หลายเท่า) — ลิงก์ไปเครื่องมือเต็มหรือใช้สูตรเดียวกัน
- **ค้นหา** (`searchCatalog`): หาจากชื่อ/blurb อย่างเดียว ไม่มีคำพ้องหน้างาน เช่น “แรงดันตก”, “ยาแนว”, “ทับหลัง”, “ลูกตั้ง”
- **รางน้ำหลังคา** อ้างแนว SMACNA ฝนสหรัฐ — ฝนออกแบบไทย 150–200 มม./ชม. ราง/ท่อลงเล็กไปได้
- เทสยึดค่ายังไม่ล็อก P–T, ทับหลัง, ท่อ PVC, โซลาร์, บันได — ตอนนี้ครอบแค่เรือธง

## 2. UX/UI ที่ควรแก้

เรียงจากสิ่งที่ทำให้ใช้ผิดบนหน้างาน ไปถึงของที่ทำให้ดูเป็นผู้ช่วยเก่งขึ้น

### P0 / P1 — ใช้ผิดได้ถ้าไม่แก้

1. **Validation เป็นข้อความใกล้ช่อง ไม่ใช่แค่ HTML min/max**  
   ตอนนี้สูตรยัง `Math.max` / fallback / ตอบต่อเมื่อค่าหลุดช่วง (อุณหภูมิสายไฟ > 60 °C, วงจร > 9, สามเหลี่ยมเป็นไปไม่ได้, หน่วยคนละชนิด)  
   ควร: หยุดคำนวณ + บอกว่าต้องแก้อะไร เป็นประโยคภาษาช่าง

2. **ช่องที่ไม่เกี่ยวกับโหมดยังโชว์**  
   ตัวอย่าง: เลือกกรอกแอมป์แล้วยังเห็นช่องวัตต์; เหล็กเลือก H แล้วยังเห็นช่องแผ่น/ท่อ; หลังคาเมทัลแล้วยังเห็นแผ่นกระเบื้อง/ตร.ม.  
   ควร: conditional fields ตามที่เลือก

3. **ป้ายความเสี่ยง A/B/C ต้องอยู่เหนือคำตอบเสมอ** ไม่ใช่แค่ในบล็อกสูตรที่หุบอยู่  
   โดยเฉพาะหน้า job ที่รวมหลายสูตร — ตอนนี้คำเตือนชั้น C หายได้

4. **โหมดผลลัพธ์ 2 แบบ**  
   - “สรุปสั่งของ” (ถุง / กล่อง / ไซซ์ที่ร้านมี)  
   - “อธิบายสูตร” (สำหรับส่งช่างหรือตรวจงาน)  
   ค่าตั้งต้นคือสรุปสั่งของ ตามหลักมือถือหน้างาน

5. **คำอังกฤษ/เทคนิคไม่มีคำไทยติด**  
   `PF`, `EER`, `MPPT`, `DoD`, `SH/SC`, `Flow + Head`, `Best Fit`, `self-level`, `kerf`, `overlay`  
   ควรมีคำไทยสั้นใน label เช่น “เพาเวอร์แฟกเตอร์ (PF)”, “ค่าประสิทธิภาพแอร์ (EER)”

6. **ความชันหลังคาเป็น %** (`unit: "%"` default 30)  
   ช่างไทยพูดองศามากกว่า ถ้าเผลอใส่ 30 แล้วนึกว่า 30° พื้นที่จริงจะขาดประมาณ 10%  
   ควร: สลับหน่วย % / องศา และโชว์เทียบ “30% ≈ 17°”

### P2 — ใช้ง่ายขึ้น หลงทางน้อยลง

7. หน้าแรกยังเข้าแบบ “เลือกสายงาน” เป็นหลัก — เพิ่มทางเข้า **“วันนี้จะทำอะไร”** (สั่งกระเบื้อง, เลือกแอร์, เดินสาย, คิดปูน) แล้วพาไปเครื่องมือ  
8. ค้นหา: synonym + ประวัติคำค้น + ผลลัพธ์ว่างที่บอกคำใกล้เคียง  
9. Search combobox: เพิ่ม `aria-activedescendant` / id ของ option ให้คีย์บอร์ดครบ  
10. ลด emoji ในหัวข้อย่อยของบล็อกสูตร (`FormulaNote`) เป็นคำไทยเรียบ: สรุป / วิธีคิด / ข้อควรระวัง / อ้างอิง  
11. หน้า job: ปุ่มถัดไปชัด — คัดลอก BOM, แชร์ไลน์, บันทึกรูป, เปิดเครื่องมือย่อยที่ถูกย่อมา  
12. มือถือ: ช่องสำคัญก่อน, แถบคำตอบล่างไม่ชนคีย์บอร์ด **และไม่ทับปุ่มแชท/แบนเนอร์คุกกี้**, empty/error บอกว่าต้องแก้อะไร  
13. แสดงช่วงค่า (low–mid–high) สำหรับสูตรแนวปฏิบัติ T5 เช่น BTU, เผื่อกระเบื้อง — ไม่ให้ค่าเดียวดูเหมือนวิศวกรรม  
14. Checklist สั้นก่อนสั่งของ: วัดหน้างานแล้วหรือยัง / เผื่อเสียกี่ % / เปิดคู่มือรุ่นหรือยัง  
15. เปรียบเทียบ 2 ทางเลือกในเครื่องมือเดียว (สาย 2.5 vs 4, แอร์ 18k vs 24k)

## 3. หัวข้อสายงานที่ควรเพิ่ม

เลือกจากงานที่ช่างไทยทำบ่อย และร้าน Blacksmith ขายของเกี่ยวได้ ไม่ใช่เพิ่มเพื่อให้ครบตำรา

### ควรมีรอบถัดไป (ใช้บ่อย / กันของพัง)

| สายงาน | เครื่องมือที่ควรมี | ทำไม |
|---|---|---|
| งานกันซึม / ดาดฟ้า | ปริมาณเมมเบรน+ไพรเมอร์, ความลาดไปท่อน้ำทิ้ง, จุดเข้ามุม | รั่วแล้วรื้อแพงกว่าซื้อของเกิน |
| งานผนังเบา / โครงคร่าว | โครง C/U, แผ่นยิปซัมผนัง, ฉนวน, สกรู/ม. | คนต่อเติมบ้านใช้บ่อย ตอนนี้มีแต่ฝ้า |
| งานประตู-หน้าต่าง | มุ้งลวด, ซีลยาง, ลูกล้อ, door closer, ช่องเผื่อวงกบ+PU foam | ต่อจากกระจก-อลูฯ ที่มีอยู่แล้ว |
| งานสุขภัณฑ์ห้องน้ำ | ระยะกับดัก (trap), ความลาดท่อโถ, จำนวนข้อต่อ/ฟิตติ้งตามแบบห้อง | ประปาตอนนี้ยังไม่แตะสุขภัณฑ์ |
| งานไม้แผ่น 4×8 | cutting list, ระยะสกรูขอบ, sag ชั้นวาง | บิ้วอินมีลามิเนตแล้ว แต่ยังไม่มีแผนตัดแผ่น |
| งานประมาณราคาหน้างาน | BOM + ค่าแรงคร่าว + เผื่อขนของ + เผื่อเสีย รวมส่งลูกค้า | จุดขาย “ส่งต่อทีม/ลูกค้า” จะครบ |

### มีแล้วแต่ควรแตกหัวข้อย่อย

- ไฟฟ้า: ตารางขนาดท่อร้อยสาย, โหลดหลอด/พัดลมรวมวงจร, เครื่องตัดไฟรั่ว (RCD)
- แอร์: ตำแหน่งคอยล์ร้อน-ระบายอากาศ, ขาแขวน/น็อต, สายน้ำทิ้งคอยล์เย็น
- หลังคา: ตะเข้ราง (valley) + แผ่นกันซึม — ตอนนี้บอกว่าไม่รวม แต่ไม่มีเครื่องมือ
- ก่อฉาบ: เสาเอ็นแนวตั้งทุก 3–4 ม. (tip มี เครื่องมือยังไม่มี)

### อย่าเพิ่งทำถ้ายังไม่ล็อกสูตรชั้น C

PPE / lockout-tagout / นั่งร้าน — สำคัญแต่ถ้าทำไม่ครบมาตรฐาน จะอันตรายกว่าไม่มี  
งานคอนกรีตเทเสา-คานรับน้ำหนัก — มีสัดส่วนผสมแล้วและจัดชั้น C ถูกทิศ อย่าขยายเป็น “แบบโครงสร้าง”

## 4. สิ่งที่โอเคแล้ว (ไม่ต้องแก้ในรอบนี้)

- โครงหลักการใน `docs/assistant-formula-principles.md` ชัด ใช้เป็นกติกา PR ได้
- สายไฟฐาน 40 °C ตาม วสท. 5-20 / 5-43, เลือกเบรกเกอร์ก่อนแล้วค่อยเลือกสาย, สายดินตาราง 4-1 — ทิศถูกแล้ว
- แรงดันตกใช้ ρ ที่ 70 °C (0.0225) และเกณฑ์ 3% / 5%
- ยาแนวแยกความหนาแน่นซีเมนต์ / เกรดสูง / อีพ็อกซ์ ตาม ISO 13007
- อิฐคิดจากเรขาคณิตก้อน+แนวปูน ไม่ใช่ตารางตายตัว; ปูนกาวมวลเบาแยกจากมอญ
- ซิลิโคนหน่วย ม. × มม. × มม. = มล. ถูกแล้ว (เคยคูณพันเกิน)
- ปูนฉาบแยกคีย์ `pkind` ไม่ทับชนิดอิฐ
- ชั้น C มีข้อความสงวนสิทธิ์กลาง `DISCLAIMER_C` และ `FormulaNote` โชว์ตอนหุบสูตร
- มือถือ: คู่ช่อง, แถบคำตอบล่าง, sticky ผลทางขวาจอ lg, `@container` ของการ์ดคำตอบ
- ของนับชิ้นปัดขึ้น (ถุง กล่อง หลอด แผ่น)
- หน้ารวม 13 การ์ดสายงาน + ค้นหาใน hero ทิศทางถูก

## ลำดับที่แนะนำให้ลงมือ (ยังไม่แก้ในรีวิวนี้)

1. ปิด P0 ทั้ง 7 ข้อ — **ตาราง P–T ก่อน** แล้วตามด้วยสายไฟเกินตาราง, ท่อ PVC จาก ID, job แอร์/ก่อฉาบคำเตือนหล่น, ลวดเชื่อมชนิดแนว, BTU คูณซ้ำ
2. แก้เหล็กทับหลังที่คูณเกิน ~3 เท่า และพุกที่ยิปซัมไม่ดูน้ำหนัก
3. ทำ error state จริง — ห้ามตอบเลขเมื่ออินพุตเป็นไปไม่ได้
4. ยกระดับหน้า “คิดทั้งงาน” ให้มีสูตร+ชั้นความเสี่ยงครบ โดยเฉพาะไฟ / โครงสร้าง / บันได
5. เปิดช่องเผื่อเสียที่ยังซ่อน, ย้าย magic number เข้า `constants.ts`, ล็อก golden test ให้ P–T / PVC / ทับหลัง
6. เก็บ UX: ช่องตามโหมด, คำไทยติดเทคนิค, ความชันหลังคา %, ป้าย A/B/C เหนือคำตอบ
7. ค่อยเพิ่มสายงานกันซึม / ผนังเบา / ประตูหน้าต่าง เมื่อของเดิมชั้น C นิ่งแล้ว
